measurement; the current design is `docs/ENGINE-SPEC.md` and `docs/ARCHITECTURE.md`.

| file | written | what it was |
|---|---|---|
| `RESEARCH-TRACK.md` | 2026-10-21 | the research agenda: candidate levers, falsification order, kill criteria |
| `PS5-PROBE-RUNBOOK.md` | 2026-10 | how the pre-engine probe battery (`tools/ps5probe/`) was run on the console |
| `RUNTIME-SPEC.md` | 2026-11-03 | the first engine design (HIP + DP4A), before the GPU was measured |
| `PROTOTYPE-PLAN.md` | 2026-11-06 | the Vulkan prototype plan that became `runtime/` |

References to `research/lab-notebook/` and to session handoffs point at the development log, which is not part of
the public repository.
